An open-source hardware media player and audio recorder powered by an ESP32-S3 microcontroller and a VS1053B hardware audio codec. This board supports MP3/AAC/WAV playback, line/microphone audio recording via MicroSD card storage, USB-C fast charging, and dedicated tactile media controls.
